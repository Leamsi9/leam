LEAM · OPERATIONS

Recovery

Independent access to your candidate services, even when the main app is unavailable.

Sign in

Use the separate pairing code from your recovery installation. Choose a recovery password; your main Leam password is separate.

Candidate services

Only the three candidate services can be started or restarted here. A reachable port confirms a listener, not a successful model response. Host wake is not configured.

Maintenance

Pause new work and let accepted work finish before restore or a planned restart. Native Coding jobs are checked, never interrupted. Your original shared Codex session stays running. The main app pauses during maintenance. Keep it on through operator verification and rollback; end it explicitly to test the main app. If accepted work needs an approval or answer, end maintenance, answer it in Leam, then prepare again.

Restore product state

Restore a local snapshot of Leam's settings, memory and commitments. Codex and Companion transcripts, external actions and runtime tool permissions stay outside this snapshot. Restore and rollback pause scheduled automations until you review and resume them in Leam Settings.

Operation receipts

Recovery runs separately. Keep this address and your recovery password available.
